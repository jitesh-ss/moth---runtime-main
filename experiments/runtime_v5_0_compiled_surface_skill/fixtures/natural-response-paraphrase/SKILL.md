# Natural response paraphrase

## Workflow

- Examine the confirmed semantic outcome prior to drafting the reply.
- Determine the requested answer length and fall back to normal detail when no recognized cue is present.
- Lead with the selected outcome before describing validity and its cause.
- Express all important values as prose joined into a coherent answer.
- Eliminate redundant wording before returning the response.

## Fidelity

- Retain all important outcome values without adding a plan, status, or cause that was not verified.
- Fail closed for an invalid outcome or an unrecognized formatting request.
- Attach the reply to the confirmed semantic outcome and the compiled instructions.

## Size

- Respect the short, normal, or expanded word allowance selected for the response.

## Completion

- Complete only when semantic coverage, natural prose, and response length have been validated.
- Return just the validated prose answer.
