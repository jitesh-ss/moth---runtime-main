# Runtime 5.0 compiled Surface skill

This isolated experiment tests whether a normal agent skill can compile into a
bounded Runtime 5.0 Surface policy that turns verified structured decisions
into natural, context-sensitive, size-controlled prose without semantic drift.

The experiment imports the unchanged Runtime 5.0 kernels, but creates a fresh
temporary store and disposable three-World bundle for every campaign. Candidate
Surface assets remain under this experiment. Production source, configuration,
architecture locks, launchers, stores, and prior experiments are read-only.
