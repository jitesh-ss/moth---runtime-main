# Runtime 4.7 Product Description

Runtime 4.7 is Moth’s canonical closed-world reasoning runtime. Users compile a
bounded language and code description into a persistent proof-carrying energy
field, then ask prompts that may only select and compose meanings already in
that field.

It supports exact lookup, directional chains and mixed-relation sequences to
depth 50, typed structured values, schema-validated canonical JSON, linear
compiled programs, provenance-backed Python structure questions, verified inert
patch plans, and inert tool-call-shaped JSON. It never executes code, applies a
patch, dispatches a tool, learns from a prompt, or copies an uncompiled prompt
value into output.

An answer requires a unique zero-violation energy minimum and independent proof
verification. Otherwise the runtime returns a stable typed refusal. Every proof
contains ordered semantic edge identifiers and complete source provenance, and
every recorded episode replays byte-exactly without an encoder.

Runtime 4.7 is designed for reliability inside a compiled world, not unrestricted
natural-language generation. Multimodal adapters may later ground to the same
canonical meaning identifiers without changing exact semantic settlement.
